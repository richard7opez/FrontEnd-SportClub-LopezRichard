# Declaración de uso de Inteligencia Artificial

## Proyecto: SportClub

Durante el desarrollo de este proyecto se utilizaron herramientas de Inteligencia Artificial como apoyo en distintas etapas del trabajo.

## Herramientas utilizadas

- ChatGPT (OpenAI)
- GitHub Copilot
- Gemini (Google)
- Microsoft Copilot
- Herramientas de asistencia integradas en Visual Studio Code

## Uso realizado

Las herramientas fueron utilizadas para:

- Generación de estructuras HTML5.
- Generación de estilos CSS3.
- Corrección de errores de sintaxis.
- Optimización de código.
- Generación de ideas para interfaces gráficas.
- Organización de archivos y carpetas del proyecto.
- Apoyo en la documentación técnica.
- Revisión de enlaces y navegación entre páginas.

## Participación del estudiante

El estudiante revisó, adaptó y modificó el contenido generado por las herramientas de Inteligencia Artificial, realizando ajustes en diseño, estructura, organización y presentación final del proyecto.

## Tecnologías utilizadas en el proyecto

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
